Force Refresh Browser Cache

Paksa browser untuk reload semua file JavaScript & CSS terbaru

⚠️ MASALAH YANG DIPERBAIKI:

• Barcode masih tampil "N/A" padahal sudah digenerate
• Format harga masih "Rp 20000.00" bukan "Rp 20.000"
• Format stok masih "10000 pcs" bukan "10.000 pcs"

PENYEBAB: Browser menggunakan file JavaScript LAMA yang di-cache.

📋 Cara Hard Refresh (Pilih salah satu):

  1. Windows:
    Tekan Ctrl + Shift + R
    atau Ctrl + F5
  2. Mac:
    Tekan Cmd + Shift + R
  3. Manual Clear Cache:
    Buka DevTools (F12) → Tab Application → Clear Storage → Clear site data
✅ Cache clearing berhasil! Silakan refresh halaman utama SIUPIN dengan hard refresh.

✨ Setelah Refresh, Cek Apakah:

  1. ✅ Barcode tampil sebagai gambar SVG (bukan "N/A")
  2. ✅ Harga tampil: "Rp 20.000" (ada titik ribuan)
  3. ✅ Stok tampil: "10.000 pcs" (ada titik ribuan)
  4. ✅ Data baru yang disimpan memiliki barcode di database
