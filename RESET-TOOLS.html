🔧 Reset Manual via DevTools

Jika semua metode di atas gagal, lakukan reset manual:

  1. Tekan F12 untuk buka DevTools
  2. Pilih tab Application (Chrome) atau Storage (Firefox)
  3. Klik Local Storage → http://localhost:3000
  4. Klik kanan → Clear All
  5. Atau hapus key: umkm_presets, user_umkm_presets, is_super_admin_logged_in
  6. Hard refresh: Ctrl + Shift + R

💡 Setelah reset, hard refresh browser dengan Ctrl + Shift + R
